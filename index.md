# Illustrating Internal Documentation Without a Designer

Internal wikis are walls of text. A small number of well-placed visuals makes onboarding pages easier to scan. Here is the lightweight process our team uses.

## Diagrams first
Architecture and process flows should be real diagrams (Mermaid, draw.io), never generated images — they need to be accurate and editable.

## Header images for orientation
Each major section of the handbook gets one consistent header illustration so readers know where they are. We generate these with the [Seedream 5.5 AI image generator](https://seedream5-5.net/) using a fixed style prompt: "flat isometric illustration, pastel blue and grey, simple shapes, no text".

## One style guide
Store the style prompt, dimensions (1600×400) and file naming in a single page. Anyone adding a section reuses it.

## Accessibility
Every image gets alt text describing its purpose, and no information lives only in an image.

## Maintenance
Decorative headers rarely go stale; screenshots do. We date every screenshot and review them quarterly.
